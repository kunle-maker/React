# VesselX Frontend — Local Setup

## Requirements
- Node.js 18+ (https://nodejs.org)

## Steps

1. Extract this folder anywhere on your computer
2. Open a terminal inside the folder
3. Run: `npm install`
4. Run: `npm run dev`
5. Open your browser at: http://localhost:5000

## Notes
- The app connects to the live VesselX backend automatically via `src/utils/api.js`
- To build for production: `npm run build` (output goes to `dist/`)
- To preview the production build: `npm run preview`
